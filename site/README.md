# m2smart.ir landing page

A single static page (`index.html`) for the public domain: what M2smart is, and that sign-in codes and invitations come by SMS. The SMS provider's reviewers open this site before approving message patterns.

- No external files (fonts, scripts, CDNs), so it opens on Iran's national internet.
- Upload `index.html` to the web root (`public_html`) of any host; nothing else is needed.
